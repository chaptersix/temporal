- Reuse CHASM command deduplication (`handler.go:185–207`, engine update at
  `service/history/chasm_engine.go:623–637`), independent of cap4 retained start
  records. Nonempty request IDs are first-success-wins even with a changed body;

  starts (invoker_tasks.go:689–692). Carryover/completion participation follows
  the admitted policy, including ALLOW_ALL exclusion.

  Unspecified override adopts current policy when transferring accepted pending

  Once queued, preserve identity/policy and sample current template/carryover at

  Existing CHASM backfiller_tasks.go:107–129 waits and scheduler.go:246–256 rejects
  excessive outstanding backfillers. Legacy full-buffer dropping is a documented
  difference. SKIP/BUFFER_ONE can still legitimately dispose under overlap policy.

## D43–D46 implementation agreement

D43: cap4 durable pending manual commands, monotonic per-incarnation uint64 sequence;
sequence exhaustion rejects before mutation. Occurrence identity manual/sequence is
independent of command RequestId, timestamp and automatic cursor. Pending records
hold sequence, nominal ScheduledTime and overlap override only. CHASM WithRequestID
owns dedup; duplicate errors become successful no-ops. Failed/over-capacity commands
are not recorded. Retention uses existing CHASM policy, not operation cap4.
D44: pending task transfers at most1 command when queue has space and an admission
can progress. Full queue waits, including before SKIP/BUFFER_ONE disposition. Resolve
unspecified override at transfer; freeze workflow-ID suffix then. Direct ALLOW_ALL
requires an operation slot; blocked tracked policies may enqueue without a slot.
No busy loop under external capacity wait; result/configuration/drain transitions
recheck pending work. Task identity uses token and execution-clock deadline.
D45: queued/manual operations carry manual sequence. Manual entries remain eligible
while paused, action-exhausted or outside catchup. Their admission never decrements
RemainingActions or advances automatic cursor. Start IDs distinguish same-time
commands; public workflow IDs retain timestamp suffix. Freeze ALLOW_DUPLICATE reuse.
Explicit ScheduledTime is identity even when in future; absent uses acceptance clock.
D46: manual task uses current configured template at transfer/admission and existing
60s immutable admission horizon. Dedicated command metadata avoids loading payloads
on acceptance/validation. Same queue effect and completion rules apply. Future
backfill work must add explicit fair arbitration; this slice makes no sustained
mixed-ingress fairness claim. No public production routing changes.
