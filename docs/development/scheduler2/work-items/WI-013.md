D57: modernize the independent executable specification to explicit immutable
source identity/revision, origin, terminal cache and exact nanosecond times.
Represent the supported lower-bound-minus-one-nanosecond sentinel as zero, with
all supported instants shifted by the same offset; never round fractional cursors.

the supported upper actual-time bound is separate from that nominal definition
end. Jitter crossing a spec end is permitted within the supported time domain.

than assuming the desired output. Source ordering, eligibility and jitter stream
correctness are explicit hypotheses, independently checked by Go oracle examples
and generated comparisons; timezone implementation correctness is not proved.

The executable may be simplified with a reviewed semantic version change, but
must preserve accepted enumeration/update/range behavior. Record differences from
the old executable and concrete regression witnesses. Theorems must apply to the
actual new executable, not a tautological declarative reference or assumed outputs.

## Required deliverables

1. Reviewed statements and machine-checked proofs of completeness and uniqueness
   across finite positive-budget resumptions, including pending jitter and both
   probe-yield/output-limit stops. Prove sufficient-resource completion from
   reachable continuations, initialization and invariant preservation. Prove
   adjacent and finite nondecreasing-window batching equivalence. Retain pending,
   update/rebase and probe-bound obligations; no proof shortcut using sorry/admit,
   project axioms or native_decide trusted evaluation. Audit exported theorem axioms.
2. Versioned executable Lean JSON oracle, compiled once per run. Explicit initial
   continuation, windows, budgets, definitions, update and historical peek/dispose/
   rebase inputs and observations. Reject unsupported schema/events. Freeze and
   review the wire contract before building a separate Go adapter.
3. Bounded exhaustive and Rapid comparisons with production Go. Construct ordered
   streams independently of production NextTimeCandidate, including concrete short
   specs via direct eligibility oracle. Preserve exact identity, disposition,
   pending, status and work-budget observations; normalize only named abstractions.
   Public validation limits may be checked in the Go adapter rather than theorem
   arithmetic, but cannot disappear from correspondence claims.
4. Standalone saved JSON replay, mutation sensitivity for lost pending/cursor skip/
   duplicate output, source/tool/binary hashes, exact bounds/seeds/timeouts and
   retained failures. Compilation/examples alone do not satisfy proofs. Independent
   proof-statement/source review and Go-oracle review before acceptance.
