## Accepted design input

D29: strict sequential SKIP occupancy starts at admission and includes Pending,
Started and Ambiguous until Completed. DIV6 versus legacy acknowledged-run-only
occupancy prevents overlap after lost acknowledgment. Due/catchup use actual time;
identity/cursor use nominal. Skips advance disposition without budget debit.
D30: cap4 retained operation records, one active slot. Atomically evict oldest
Completed record when admitting at capacity; never evict unfinished work. Cursor,
counts and carryover outlive eviction. Older retained/evicted operation messages
are no-ops and cannot change active identity or latest carryover. Bound is local,
not a production/time-based retention promise. An impossible all-unfinished full
state returns explicit capacity error without committing an occurrence.
D31: separate generator component with persisted token/deadline and separately
loaded immutable definition/template. Configure/update uses WI002 Begin/Update;
Run probes<=8, outputs<=4 and commits continuation+dispositions+operations+tasks
atomically. Waiting arms pending actual time; Yield/Limited arms now+1ms; terminal
enumeration leaves no timer. Token+deadline invalidate duplicate/old deliveries.
Catchup is explicit nonnegative duration. No clock outside [2000,2101) accepted. Continuation deadlines clamp to the last
supported instant; tokens allow same-instant resumption at the range boundary.
Catchup maximum 365 days; seed/template max 64KiB each. Generated workflow IDs append
nominal UTC RFC3339, matching the existing automatic-workflow naming convention.
