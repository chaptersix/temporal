## Goal

Connect scheduler2's persisted decision/task machinery to actual workflow start,
History completion callbacks and chain-fenced cancel/terminate; support nonempty and
unpaused public creation, initial patches, Update/Patch/MatchingTimes and live public
projections. Run the existing shared ScheduleSuite using an actual scheduler2 backend.
This is the full M3 execution endpoint; dependency ordering does not narrow its scope.
Keep all selection in explicit dedicated local test clusters, default production
routing unchanged, independent typed identity/visibility, and no old-backend fallback.

## Contract and investigation

D59 decisions are in `../design/public-execution-contract.md`; source-backed gaps
are in `../evidence/wi014/next-execution-investigation.md`. They cover complete request
assembly, frozen request-ID callback envelopes, real completion translation, start-error
classification, prototype/public bound reconciliation and public token/dedup semantics.

Bound accounting is now source-resolved in the draft contract: preserve existing
configured frontend validators, validate actual generated callback bytes, remove
prototype64KiB/128KiB acceptance ceilings, and preserve accepted internal callback
payloads without retroactive config rejection. CHASM mutable-state capacity remains
finite (default8MiB); avoid duplicate persisted large payloads and verify aggregate
capacity rather than inventing a new public cap. The4MiB transaction setting applies
to inspected history-batch checks, not a demonstrated universal CHASM node cap.
First-run identity must use actual Start response.FirstExecutionRunId; never substitute
RunId when the canonical first ID is absent. No user contract escalation is currently
required by the inspected evidence.
