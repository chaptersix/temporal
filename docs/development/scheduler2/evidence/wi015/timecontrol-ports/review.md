# Time-control functional ports and cached-candidate gate repair

Three original CHASM scenarios now use backend-parametric helpers; original wrappers still select the existing CHASM backend. New standalone scheduler2 tests select the explicit scheduler2 frontend. Test bodies, stimuli, expectations and polling deadlines are unchanged. There are no skips or fallback paths.

The dynamic namespace gate scenario verifies rejection while disabled and acceptance after enabling. The max-skip scenario verifies exactly10 skips, effective disabled state, and incomplete12-week fast-forward. Both passed initially. The runtime-disable scenario verified an active child prevented advancement, namespace disable rejected further time-control patches, the child completed without skipping, then reenabling and requesting6h fast-forward completed before the first scheduled tick12h away. This final completion assertion failed in the initial run.

A temporary read-only diagnostic captured actual persisted scheduler2 state after the failure. It showed no unfinished operations or queued work, a future coordinator obligation at the pending candidate12h away, and a cached nonexcluded pending candidate. The final patch had called generator.arm(now), leaving WakeAt in the past even though automaticDemand correctly waited until pending.Actual. IsExecutionSkippable used the old WakeAt as an unconditional blocker, so the6h fast-forward never advanced. The diagnostic log is retained; temporary diagnostic code was removed.

The repair aligns the runtime gate with automaticDemand readiness. After all existing root/coordinator guards pass, a due generator wake permits skipping only when an already-cached, nonexcluded candidate has Actual strictly after now. Missing, excluded, and due candidates still block until scan/disposal/admission work runs. Tracked workflows, unresolved starts/effects, queue/manual/backfill work, reserved ownership, paused/closed schedules and due coordinator work remain blockers. Unit cases cover future/due/excluded cached candidates in addition to the original gate cases.
