# Durable list-preview continuation: isolated helper

The persisted protobuf shape is fixed: owner32, stamp, original/current typed timestamp boundaries, limited/remaining/target snapshot, <=5 completed actual timestamps, timezone fingerprint32, sampled policy pair and empty/exact328-byte raw continuation. Input validation bounds repeated output before loops/cloning and checks policy width, target, chronology and completion shape. All state changes are detached; advanceListPreview does not publish DATA or a visible prefix.

The helper uses actual DefinitionPreparation.Prepared/PreparedTimezone and page readers; Source remains untouched. One invocation calls AdvancePreparedSpec at most once with budget1..64 and completes at most one GetNextTime output. Policy getters are sampled once at logical output start, persisted through raw-work yields and resampled only for the next output. Next lookup starts after previous jittered ACTUAL, matching publicFuture. Semantic compute-limit or exhaustion completes with already completed output prefix; arbitrary page/codec errors return no replacement. Zero target requires no installed pages or timezone. Stale list stamp/owner returns before page/timezone access, then current definition owner is checked independently.

A changed timezone semantic fingerprint clears the entire unpublished window and raw work and restarts at OriginalAfter with fresh logical-output policy samples. This preserves old publicFuture's one-compiled-zone-per-window semantics. Already published list storage is never changed by this helper. Recent/notes-only mutations use prepareListDynamic and do not replace the job stamp. Root owns fair paused progress, refresh after time advances, definition/source refresh, actual task/recovery fences, ListPreview publication and atomic prepareListWindow completion.
