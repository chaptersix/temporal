# Secondary canonical Patricia count trie: prototype evidence

Scope: standalone internal/queueindex CountStore, no scheduler runtime wiring, CHASM adapter, proto, 2D outer index or two-generation implementation. This is the secondary point/range primitive only. Independent review and all remaining protocol gates precede adoption.

API: Update consumes one external root reference and returns its replacement; Fork retains another root owner; Count and CountBefore are read-only. Empty root is all-zero. Callers serialize access. Missing nodes, absent deletion, multiplicity/refcount overflow and hash identity collisions fail before staged commit. No arbitrary DropRoot API claims bounded destruction. There is no persistence importer yet, and untrusted arbitrary node graphs are not accepted through this API.

Encoding is exactly86 bytes: schema1 byte, Patricia bit1 byte, chronological key12 bytes, subtree multiplicity8 bytes, left/right SHA256 IDs32 bytes each. A leaf uses bit96; branches split at first differing bit. The store adds8 bytes of reference count per page. A keyed store additionally needs the32-byte node identity (or an encoded path). This prototype's `EncodedSize` is precisely canonical value+reference bytes, not total persisted or resident size. Canonical reuse verifies exact node contents, not hash equality alone.

Point updates path-copy immutable pages, retaining shared children when a new page is interned. The root is retained before the old owner is released. Because unchanged subtrees have the same canonical identities, only changed path pages become unreferenced. A transaction stages keyed overrides/deletions and commits only after all checks pass; errors discard the overlay. It does not clone the store. This establishes in-memory atomicity only, not CHASM persistence rollback. Full-store test audits independently recompute all edge/root reference counts and structural invariants; those scans are tests, never update code.

Conservative asserted point bounds for96-bit keys: reads<=16*97 (includes staged/backing lookups and canonical reuse probes), distinct committed node writes<=8*97, reference-release visits<=2*97, canonical hash-input encoding<=97*86 bytes. This EncodedBytes counter excludes refcount serialization and committed mutation bytes. A separate conservative value/ref write bound is94*Writes bytes (deletes overcharged), plus32*Writes bare key bytes and the eventual adapter envelopes; no actual CHASM serialization counter exists yet. CountBefore reads<=193. Full-depth adversarial shape with a distinct branch at every bit exercised increment reads1255, writes290, releases193, encoded8342 bytes. It is important that release visits count shared off-path roots even when they remain referenced.

`CGO_ENABLED=0 GOMAXPROCS=4 go test -tags test_dep -p 2 ./chasm/lib/scheduler2/internal/queueindex -count=1 -rapid.checks=100 -rapid.seed=1 -v`

Additional tests cover insertion-order-independent canonical roots, three shared owners with independent updates/rejoin/deletion, maximal multiplicity overflow after staged leaf creation, full96-bit depth, and storage/work at N=4,5,1000,10000. Root's earlier key/clock-rollback witnesses are separate evidence.

CHASM path/envelope/mutable-state accounting and Go map/heap overhead are excluded. These figures are for one secondary root. Multiplying across outer sequence ancestors can exceed the inherited8MiB execution resource limit; neither these numbers nor fixed work claim that the final multidimensional layout fits. Actual persisted and heap accounting, shared-root amplification, two-generation transitions and final capacity behavior remain mandatory integration gates.
