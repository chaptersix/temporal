# Indexed queue decision seam

The reducer accepts a fixed six-class QueueSummary and emits one ephemeral QueueChange (none, append, completed drain). Step clears the output before every event, including stale-incarnation events; auxiliary BindEffects cloning preserves a newly produced output until publication. Slice mode remains the finite reference and retains its original selection/removal loops. Indexed mode never materializes a miniature queue or invokes those loops. Queue length, BUFFER_ONE, ingress capacity and effect selection use fixed counts; queued terminate still dominates cancel regardless of eligibility.

The internal QueueDrainPlan binds exact summary/generation/version, Root, Capacity, execution time and catchup. Validation rejects mixed representations, negative/overflowing counts, missing identities, stale controls, impossible selected/first ordering, selection ineligibility, count nonconservation, explicit ineligibility and incorrect ordinary predecessor disposition. This checks structural/value consistency; it cannot prove actual record membership or extrema without storage. The keyed facade owns those bounded queries in the same transaction. Plans are never accepted as public RPC input.

On append, the reducer emits one concrete record, changes one class count and advances version. On drain, it installs retained counts, increments generation/version, sets maintenance and emits the completed plan. Physical maintenance is external and must project to a logical stutter. Maintenance defers drain only; producers may still append to the active generation. Existing Step signature is unchanged.

QueueAvailable now compares a nonnegative buffered count and queue count against the remaining capacity instead of overflowing their sum. Nonpositive public limits remain disabled. Indexed summary validation is exported for stateFor to reject malformed persisted state before scalar preview helpers; errors must propagate through caller planning paths.

Evidence07 runs the entire decision package plus100 seeded Rapid drain comparisons. Directed comparisons cover all six classes, mixed replacement, non-prefix expiry, paused/limited invalidation, no eligible entries with and without operation capacity, and selected admission with unavailable capacity. Producer comparisons cover automatic/manual/backfill, BUFFER_ONE/ALL and cancel/terminate, limits-1/0/1/5, full operation/control/effect projection, and output reset on stale/normal subsequent events. Generated comparisons vary class/time order, root controls, capacity and catchup. Negative plans exercise control fences, counts, eligibility and order. The test planner intentionally scans the finite oracle; it must never be used in runtime code.

Scoped lint04 passes normal/minimal/vet zero issues after splitting the plan validator into selection and per-class helpers. Initial lint01 complexity and lint03 import-grouping findings and all routine logs are retained. Source fingerprints are in manifest.json. Public runtime activation, persisted two-generation cleanup, actual transaction work/size bounds, and physical failure/recovery remain separate required WI018/M3 gates.
