# Root integration review

Reviewed the independent MemoVersion reservation helper and its actual publication hooks. PublicRevision is insufficient because acknowledgments and callbacks change the memo without changing the public conflict token. The provider reads only the root scalar; legacy zero values have virtual baseline one. Publication preserves the reserved value through RootState replacement, and nested list/pause publications consume the same reservation. Failure before publication leaves stored revision unchanged. Overflow is rejected before mutation. Missing or stale publication reservations are invariant failures requiring lease discard, not recoverable continuation.

The composed package run and default public integration pass (addressed-runtime/addressed-memo-full02.log and addressed-memo-public01.log). Directed cases cover acknowledgment/callback order, failed commit, nested maximum revision, generation pause, private paused projection and direct provider nonmaterialization. The root independently inspected these cases and the actual hooks. No additional blocking finding identified in this increment.

Scope: this establishes revision invalidation only. SearchAttributes still reads the full PublicList and ContextMetadata still reads PublicSchedule; those large reads must be partitioned before claiming the prepared runtime full-transaction bound. Default public regression does not prove bounded private runtime activation. The actual bounded shared suite was started separately and remains pending. Source hashes are in root-reviewed-source.json; later source changes require renewed review of affected hooks.
