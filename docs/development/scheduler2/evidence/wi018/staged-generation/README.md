# Staged generation and private public ingress

GenerationConfig accepts a private immutable staged source only for fresh prepared execution or replacement of an existing prepared source. Fixed cursor metadata preserves occurrence update semantics without rebuilding masks or resolving timezone input inside mutation. Staged replacement preflights source token, revision, binding and cleanup ownership before publishing source/control, page-retirement ownership, blob references or task fences. Replacement resets incomplete prepared work while retaining admitted requests and old installed prefixes for cleanup. Existing finite/addressed roots cannot migrate into this representation.

Private newPreparedPublicSchedule and UpdatePreparedPublic consume detached canonical ingress envelopes from the shared PreparationService. Constructor initializes unpublished static/list preview state and starts durable source preparation. Selected control patches update notes/pause without reading the full definition; old completed static/future windows survive replacement until a matching new window commits. The normal public test frontend has not been switched to these hooks. Preview maintenance, per-logical-job source checks and final prepared public suite activation remain pending.
