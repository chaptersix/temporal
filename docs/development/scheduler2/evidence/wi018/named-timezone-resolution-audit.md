# Named timezone resolution audit

Root inspected current service/worker/scheduler/spec.go and the local Go1.27.3 source recorded in named-timezone-source.json. This is a remaining runtime-integration contract, not an implemented resolver. Persisted timezone page preparation may proceed independently; it must not imply named resolution is complete.

The legacy SpecBuilder treats nonnil TimezoneData as custom data, including allocated-empty data. It bypasses the named cache and calls LoadLocationFromTZData. Named results and errors share a capacity1000,24-hour cache. Preserve the distinction between nil and empty bytes, error caching, and refresh of named snapshots; a timezone-name string is not sufficient resolved identity.

Actual Go source ordering differs from the order in the public LoadLocation documentation list. Empty name and UTC return UTC immediately; Local returns the process Local object. Other names reject any double-dot substring or initial slash/backslash. ZONEINFO is captured once lazily. A readable valid ZONEINFO directory/zip entry wins; otherwise platform sources are attempted in order, then embedded tzdata, then GOROOT/lib/time/zoneinfo.zip. Temporal cmd/server/main.go explicitly imports time/tzdata, so embedded fallback is present and precedes GOROOT in the executable. A resolver that merely reads GOROOT first changes behavior when bundles differ. Preserve actual error precedence rather than choosing a new stricter validation policy.

On Unix, platform sources are /usr/share/zoneinfo/, /usr/share/lib/zoneinfo/, /usr/lib/locale/TZ/, /etc/zoneinfo. Local initialization is separately lazy: absent TZ loads localtime from /etc (then the same embedded/GOROOT fallback); empty TZ uses UTC. A leading colon is stripped. Absolute TZ paths are read directly; other nonempty non-UTC names use platform resolution. Failed Local resolution falls back to UTC. Source resolution is outside CHASM mutations; once resolved, persist the exact prepared rules and explicit resolvedAt cache tuple, not a promise to reload the same name later.

Remaining implementation dependency: the Go embedded bundle loader is unexported. Do not use unsafe/reflection or assume a GOROOT copy is the bundle used by the server. An explicitly owned, versioned bundle and source resolver must be wired consistently with the server build, or an equally exact supported mechanism must be established. Tests must cover conflicting source contents, unavailable/corrupt earlier sources, embedded versus GOROOT precedence, Local initialization and cache refresh. No source-order shortcut or production named-route activation has been accepted.
