# Optional visibility memo revision checkpoint

Framework capability only. Scheduler providers are not opted in, and bounded transaction work/WI-018 acceptance remains open.

VisibilityMemoVersionProvider supplements Memo with a persisted nonzero uint64 revision. The application must atomically advance it for every Memo content change and reject overflow before changing projection state. CHASM cannot verify an unchanged revision against content without defeating this gate: unchanged content is an explicit provider contract. Warm backward/wrapped revisions and zero revisions fail. Registration rejects MemoVersion without Memo. No bounded-layout descriptor exists yet; its later registration checks must require this capability where the layout promises bounded memo checks.

Cold NewTreeFromDB and passive ApplyMutation/ApplySnapshot refresh only revision/presence, without Memo, clone, or equality. An active visibility-eligible close compares versions, then uses existing visibility task generation. Persisted tasks remain export authority; initializing the cache does not certify that visibility storage caught up. Lifecycle and closed-execution guards are unchanged. Raw providers retain the original Memo/Equal/Clone behavior. Actual visibility export in service/history/visibility_queue_task_executor.go still calls Memo and encodes its complete message; this output-proportional work is unchanged, not claimed bounded.

Version cache is derived in-memory state, not new persistence. It advances during close and is discarded with a failed execution lease. Reconstructing committed bytes restores the earlier revision, and retry emits visibility again. A pre-close application failure cannot advance this cache; escaping the failed tree is still unsupported. Detached/nil-library providers must implement MemoVersion without runtime config/tasks, just as Memo's read contract requires. Tests use a registry with nil handlers/config and a fixed DATA revision; a detached reader observes that same value and can explicitly export the full memo.
